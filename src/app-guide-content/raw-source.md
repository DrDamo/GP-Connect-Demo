# App Guide: Raw Source

Raw Source shows the entire loaded file exactly as it was uploaded — no formatting, filtering, or highlighting.

## What it's for

Use this tab when you want to see or search the whole file rather than one clinical item's resource. The header shows the filename, format (JSON or XML), and total line count.

## Copy

The "Copy" button copies the **entire loaded file** to your clipboard, not just whatever you've selected on screen — use text selection (below) if you only want part of it.

## Search

The same search bar used in Inspector is available here: find text anywhere in the file, with Enter/Shift+Enter to step between matches.

## Indent guides

The "Indent" toggle turns on vertical guide lines to help track nested structure in the JSON.

## Raw Source vs Inspector

Raw Source is unfiltered and shows the whole file. If you want to jump straight to one clinical item's FHIR resource with it already highlighted, use Inspector instead.
