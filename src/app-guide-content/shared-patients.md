# App Guide: Shared Patients

Shared Patients is your organisation's library of synthetic patient records saved from the Record Builder, so a team can reuse and continue each other's test data.

## Loading a shared record

"Load into builder" loads a record into the Builder as an **editable draft** — it does not jump straight into the clinical viewer. Once loaded, use the Builder's "Load into viewer" button if you want to actually see it rendered in Clinical View.

## Versioning

Each time a record is saved back to the shared library, its version number increases (v1, v2, ...), so your team can tell at a glance which copy is newest. The list also shows who created each record and when it was last updated.

## Deleting a shared record

Each row has a delete button, which asks for confirmation before permanently removing the record from your organisation's shared library.
